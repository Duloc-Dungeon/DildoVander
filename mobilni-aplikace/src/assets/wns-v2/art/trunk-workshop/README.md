# Magický kufr

Nezměněné exporty z dodaného `DildoVander-magicky-kufr-assets-v1.zip`,
28. 10. 2026. Původní `manifest.json` inventarizuje celý zdrojový balíček;
do této aplikace jsou přenesené pouze čtyři používané WebP varianty.
Jejich SHA-256 odpovídají manifestu.

Otevřený a zavřený kufr jsou samostatné ilustrace, nikoli snímky animace.
Jména, otázky, stav a ovládání patří do HTML. Prázdný podnos ani demonstrační
hůlka se nepoužívají jako náhrada uloženého osobního artworku.

Integraci a ověření popisuje `docs/magicky-kufr-workshop.md` v kořeni repozitáře.
