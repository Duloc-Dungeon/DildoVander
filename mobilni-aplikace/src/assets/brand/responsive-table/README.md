# Responsive Table artwork

Runtime WebP assets copied unchanged from the user-supplied Wand Night Stand — The Responsive Table prototype (Selected Preview 2, 26 October 2026), `public/art/`. These are synthetic decorative illustrations. Source records mark every imported asset as synthetic; byte counts and SHA-256 hashes are recorded in `manifest.json`.

Only the table scene and three spell tokens are consumed. The reference people, sample scores, local opponent logic and PNG masters are deliberately excluded. Production identity, scores, inventory, consent and game decisions remain owned by the existing game state and server.
